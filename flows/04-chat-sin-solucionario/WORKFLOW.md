# Chat web sin solucionario completo

Flujo experimental para preguntas sin pauta válida. Una pauta parcial conserva sus respuestas y justificaciones cubiertas. Consulta el [procedimiento común](../../references/workflow.md), las [interfaces](../../references/interfaces.md) y el [contrato de contenido](../../shared/references/content-contract.md) para producir el paquete. Resuelve las rutas relativas desde la carpeta de SKILL.md.

1. Comprueba en esta sesión lectura de todas las páginas y sus visuales, capacidad de recortar, espacio de contexto, ejecución Python/Node, dependencias, validación, creación y entrega de ZIP. Intenta pruebas concretas con las herramientas disponibles. Si falta algo indispensable, explica el impedimento y conserva lo realizado; no prometas un paquete inválido.
2. Solicita destino preferido salvo que ya esté indicado. Sin acceso al equipo del usuario, usa una carpeta escribible del chat, registra la preferencia mediante `--suggested-save-location` y entrega enlace de descarga. Ejecuta `prepare --host web`, lee las fuentes y crea el mapa completo.
3. Documenta la pauta parcial válida en `key.json`, si existe. Una pauta ambigua o incompatible no se aplica. Ejecuta `map` y consulta `route` con la pauta disponible: devolverá `needs_consent` si hay preguntas pendientes, sin congelar la ruta.
4. Solicita consentimiento real: «No encontré un solucionario válido para todas las preguntas. ¿Quieres usar el modo experimental para resolver las pendientes? Se recomienda un modelo con buena capacidad de razonamiento y visión. Las respuestas y explicaciones pueden contener errores». Ofrece **Continuar** o **Dejar respuestas pendientes** y espera la respuesta. Repite `route --experimental yes` o `no` según corresponda.
5. Registra lectura con `record-input` y produce lotes de hasta cinco. Usa la pauta para lo cubierto. Si el usuario aceptó, resuelve solo `solve_question_ids`; si rechazó, conserva `pending_question_ids` con respuesta y explicación `missing`. Coteja las seis dimensiones con `check-template` y `record-check`, usando evidencia visual; no simules un revisor independiente en la misma conversación.
6. Ejecuta `validate`, `pack` e `inspect`. Entrega ZIP descargable, cobertura, procedencia y pendientes. La autorrevisión no promueve estados a `verified`.
